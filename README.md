# 🌍 Travel Explorer

A modern travel exploration web application built with **React and Vite** that provides an interactive interface for exploring travel destinations.

The project demonstrates modern React development practices, client-side routing, centralized state management, and API-based data handling.

## 🔗 Live Demo

🚀 **Live Application:**  
https://travelexplorer-tau.vercel.app/

---

## ✨ Features

- 🌍 Explore travel destinations
- 🧭 Navigate between different application pages
- 📱 Responsive user interface
- ⚡ Fast development and build experience with Vite
- 🔄 Centralized state management with Redux Toolkit
- 🌐 API communication using Axios
- 🛣️ Client-side navigation using React Router
- ♻️ Reusable React components
